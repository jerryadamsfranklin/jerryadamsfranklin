## Executive Summary

I design and deploy production AI systems that create measurable business impact. My focus is applied LLM engineering, agentic workflows, and communication-efficient federated learning.

At **Digital Currency Group**, I built **VCScout-AI** (LangChain + Qwen-7B + Weaviate), an agentic RAG system that analyzed 300+ startup opportunities and supported **$450K+ in AI-informed investments**. At **Intel**, I led TensorFlow CPU optimization and received the **AIA Division Achievement Award**.
